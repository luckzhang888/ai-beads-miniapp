# AI豆仓微信小程序

基于 `develop` 分支实现的微信原生拼豆效率工具，围绕“导入图纸 → 智能转色 → 管理图纸 → 高亮辅助拼豆 → 库存核销”完成可运行闭环。

## 当前功能

- AI豆仓统一品牌与可用主导航：豆仓、图纸册、灵感库、记录、我的均为真实页面；图纸册支持统计、搜索、库存/尺寸筛选、排序、文件夹和批量管理
- 六种创作入口：图纸导入、PDF 文件入口、分享口令、图片直链、像素画转图纸、AI 智能统计；图片可标记为主图/镜像图/效果图
- MARD 221 标准色，RGB → XYZ → CIELAB → CIEDE2000 最近色匹配
- 保持比例、方形裁剪、方形留白，支持单指移动、双指缩放、旋转、镜像和生成前像素预览
- 自动去除透明/近白背景，空白格不计入豆数、色号、进度和库存
- 32 / 48 / 64 / 80 / 96 / 128 短边精度与自动推荐尺寸
- 图纸详情：主图、单色效果、色号与用量、库存缺口、状态和标签
- 图纸高亮助手：Canvas 离屏生成高清快照、微信原生图片层/movable-view 合成缩放、手势期零 setData/零重绘、松手不刷新，支持坐标尺、色号、辅助线、镜像、锁定和视图位置恢复
- 逐格、整行、矩形区域进度标记，支持撤销与逐色快速完成
- 高清完整图纸导出：坐标、5×5/10×10 辅助线、色号图例和大图分页
- 图纸编辑：画笔、填充、空白橡皮、吸管、候选近色、全局/区域换色、近色合并、颜色锁定和撤销/重做
- 本地豆仓：逐色号批量录入、手动/CSV/24–221 色套装入库、单色库存修正、多图消耗计算、目标库存补豆清单、自定义低库存、完整出入库记录、图纸缩略图关联与撤销；295 色入口仅在补齐真实 295 色卡后开放
- 图纸批量管理支持修改状态、按图纸用量入库、领料出库和撤销退料，库存记录自动关联单张图纸
- 批量图片导入：一次选择最多 9 张图片，沿用当前识别参数逐张生成图纸并容错继续
- 本地图纸分享口令、重命名、复制、删除和状态管理；文件夹支持创建、筛选、长按/按钮调整顺序、移动图纸和安全删除（真机确认弹窗兼容，删除后图纸自动移到根目录）
- “智能录入”会直接进入本地图片识别流程，自动生成网格、匹配 MARD 色号并统计用量；不依赖未配置的云端 AI 接口

## 说明与边界

- `project.config.json` 默认使用 `touristappid`，只用于本地编译检查；真机预览、相册/相机权限和上传发布必须换成自己的合法小程序 AppID。
- PDF 页面的文件选择与预览入口已保留；微信小程序端不能直接把 PDF 栅格化为图片，自动识别需要部署受控的服务端转换接口。
- 当前分享口令用于同一小程序本地数据中的图纸定位；跨设备分享需要云数据库或业务服务端。
- 图片链接提取支持可公开访问的 JPG/PNG 直链；小红书等平台分享页需要部署合规的服务端解析和配置合法域名，客户端不会伪装为已支持。
- 色卡 RGB 值用于屏幕算法匹配，实物会受到品牌批次、光线与屏幕显示影响。
- 本项目不包含 AI豆仓官方代码、素材或用户数据，界面和交互根据公开产品信息与参考截图重新实现。

## 安装与验证

```bash
npm ci
npm run verify
```

`verify` 会依次执行：

1. JSON、JavaScript、WXML、WXSS、页面资源和事件绑定检查
2. 空白识别、构图参数、色差与近色合并、导出分页、图纸进度、分享口令、库存交易和手势单元测试
3. 状态化体验回归：图纸全选/移动/删除、全 221 色调整及撤销、多图消耗合并和 100 次连续缩放事件合并
4. 使用微信 `miniprogram-ci` 完成本地编译

也可以分别运行：

```bash
npm run check
npm test
npm run test:ux
npm run compile:local
```

## 微信真机预览二维码

官方预览必须使用目标小程序的合法 AppID 与代码上传密钥。把以下仓库 Secrets 配置到 GitHub Actions：

- `WX_APPID`
- `WX_PRIVATE_KEY`

推送到 `develop` 后，`wechat-preview` 工作流会生成 `preview-qrcode.png`，并上传为 `wechat-preview-qrcode` Artifact。私钥仅在工作流运行时写入，不会提交到 Git。

本地也可以运行：

```bash
WX_APPID=你的小程序AppID WX_PRIVATE_KEY_PATH=private.key npm run preview
```

Windows PowerShell：

```powershell
$env:WX_APPID = '你的小程序AppID'
$env:WX_PRIVATE_KEY_PATH = 'private.key'
npm run preview
```
